### 🌟 What's New in v1.2.3

Guidegram v1.2.3 delivers seamless version synchronization and dedicated inline updater controls within the Settings interface.

#### 🔄 Dynamic Real-time Version Synchronization
- **Live IPC Querying**: Connected the renderer interface directly to runtime Electron process (`app:get-version`), preventing static bundler cache mismatches.
- **Unified Identity**: Ensures displayed client version perfectly reflects the actual running binary across all screens.

#### 📥 Inline Download & Update Actions
- **Direct Update Button**: Added `Download & Update Now` action button directly within the Software Updates settings card.
- **Visual Progress Feedback**: Real-time progress bar reflecting archive download chunks, verification, and automated extraction without touching user accounts or session data.
- **Clear Up-to-Date Indicator**: Eliminates ambiguity by explicitly confirming when the client is running the latest release.
